# ⟨ HUNTER GATE ⟩ : Gym Log Tracker

### **"I alone level up. The dungeon awaits."**

**Hunter Gate** is a premium, gamified training log designed for those who want to turn their fitness journey into an epic quest. Built with a high-fidelity, dopamine-inducing UI inspired by the "Hunter System" (Solo Leveling), it transforms every workout into a raid, granting XP, ranks, and achievements as you conquer your limits.

---

## ✦ System Overview

Hunter Gate is more than just a workout tracker; it is a **Player Growth Interface** that evaluates your battle data (weight, reps, sets) and calculates your evolution in real-time.

### **Core Features**

*   **⚔️ Raid Logging**: Record every set with precision. The system calculates session volume and grants XP based on intensity and streaks.
*   **📊 Stat Scaling**: Your strength (STR), vitality (VIT), and agility (AGI) stats are automatically adjusted based on your performance in the "field" (Big 3 total, consistency, and exercise variety).
*   **🏆 Hunter Ranking**: Progress from **E-Rank** to the legendary **S-Rank (Shadow Sovereign)**. Your rank is a testament to your grind.
*   **📜 Daily Quests & Penalties**: Complete daily objectives to maintain your streak. Beware the **Penalty Quest**: neglecting your training for too long transports you to the survival zone.
*   **📉 Advanced Analytics**: Deep-dive into your growth with Line Charts (Strength Trends), Radar Charts (Muscle Balance), and Activity Matrices (Heatmaps).
*   **🔓 Achievements**: Unlock unique titles and milestones as you hit new personal records.

## 🛠️ Technology Stack

*   **Frontend**: React Native (Expo)
*   **Navigation**: React Navigation (Native Stack & Bottom Tabs)
*   **Storage**: Local-first architecture using AsyncStorage (no cloud required, your data is yours).
*   **Charts**: React Native Chart Kit
*   **Icons**: Ionicons & Material Community Icons via Expo Vector Icons

## 🚀 Getting Started

To initialize the Hunter System locally:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Ragulprasath52/Hunter-s_gate.git
    cd Hunters_gate
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Start the System**:
    ```bash
    npx expo start
    ```

4.  **Launch Mobile**: Use the Expo Go app on your physical device or run on an emulator:
    ```bash
    # For Android
    npx expo run:android
    ```
